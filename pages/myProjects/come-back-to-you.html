I. Introduction & Gameplay

Come Back to You is a 2D platformer built in Unity. Players navigate challenging levels featuring moving platforms, buttons, automatic doors, teleporters, and traps like the dirt snake.

II. Technical & Code Structure

Developed in Unity with a clean, component-driven 2D architecture utilizing the new Input System and UI Toolkit.

Code Architecture

  • Player Mechanics: PlayerBehavior.cs, PlayerInputHandler.cs, KillerBehavior.cs, and KillerDied.cs control movement, physics interactions, and player state.
  • Platforms & Puzzles: AutoPlatformX.cs, AutoPlatformY.cs, ButtonAndPlatformX.cs, ButtonAndPlatformY.cs, ButtonDoor.cs, EndDoor.cs, and TeleportButton.cs manage interactive environment logic.
  • Traps & UI: DirtSnakeMovement.cs, TrapBehavior.cs, MainMenu.cs, PauseMenu.cs, and BackStory.cs handle hazards and game state UI.
