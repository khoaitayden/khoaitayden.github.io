I. Introduction & Videos

Horses ML Agent is an artificial intelligence and reinforcement learning project built in Unity using the ML-Agents framework. The project trains autonomous horse agents to master racing tracks, hit checkpoints efficiently, and optimize movement policies through reward-based training.

II. Technical & Code Structure

Developed using Unity ML-Agents, custom reward functions, and ONNX neural network model integration.

Code Architecture

  • ML-Agent Behavior: HorseAgent.cs inherits from Agent, defining observation spaces, discrete/continuous actions, and reward shaping functions for tracking and checkpoint navigation.
  • Race Management: RaceManager.cs controls race logic, start/finish lines, checkpoint validation, timer systems, and episode resets.
  • Trained Models: Multiple generations of ONNX reinforcement learning models (`AIModel/`) trained across iterative training sessions and hyperparameters.
