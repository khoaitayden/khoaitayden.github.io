I. Introduction

Under the Mask is a narrative puzzle and dialogue game created during Game Jam Vietnam 2026. Players interact with patients, analyze symptoms, uncover psychological illnesses, and navigate branching conversations where people hide behind emotional masks.

Gameplay Video

II. Technical

Built in Unity featuring Ink narrative scripting, modular ScriptableObject data layers, UI event setups, gameplay/dialogue design, and custom wire sound design.

Core Systems & Contributions

  • Narrative & Dialogue: Integrated Ink dialogue scripting engine (`Bang.ink`, `Thuan.ink`, `Trinh.ink`) for branching conversations. Dialogue flow and gameplay mechanics co-designed alongside Nguyen Tung An.
  • Data Architecture: Modular ScriptableObject architecture managing Illness, Patient, and Symptom data structures across Data and Controller layers.
  • UI & Event Setup: Custom UI layout, screen interactions, and game event triggers using DOTween and TextMeshPro.
  • Sound Design: Atmospheric wire sound design and audio mixing.
