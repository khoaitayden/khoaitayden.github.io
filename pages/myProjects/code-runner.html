I. Introduction

Code Runner is a puzzle programming game where players solve grid-based challenges by sequencing movement, action, and loop commands. Think like a programmer to navigate obstacles, execute algorithms, and beat each level efficiently.

Gameplay Video

II. Technical & Code Structure

Built in Unity with a modular command-pattern architecture, JSON-based level serialization, and drag-and-drop UI command slots.

Code Architecture

  • Command Pattern: Command.cs, CommandSlot.cs, and DraggableCommand.cs handle the drag-and-drop instruction logic and execution queue.
  • Loop & Flow Control: LoopPanelController.cs manages repeating loops and nested instruction blocks.
  • Board & Player: BoardManager.cs manages grid tiles and obstacles, while PlayerController.cs executes queued movement instructions.
  • Data & Serialization: LevelData.cs, CompactLevelData.cs, and JSON level files stored under Assets/Data/Levels/.
  • Audio System: AudioManager.cs, MusicManager.cs, and SFXManager.cs managing retro 8-bit sound effects and chiptune background music.
